# Monitor Set Examples

This directory contains examples of operational monitor sets that can be imported into LogicVein ThirdEye and ThirdEye Suite.

For instructions on importing monitor sets, see the [ThirdEye online manual](https://docs.logicvein.com/manuals/thirdeye-en/monitormultipledevices/).

Each example folder contains a README describing its purpose, prerequisites, installation steps, and any additional requirements.
