# Deprecated Device Inventory Export Examples

These Perl and Ruby scripts are the original CSV device-inventory exports. They use username-and-password authentication, disabled TLS verification, a fixed managed network, and older positional or incomplete pagination conventions.

They are retained only for historical inspection and should not be used on a current netLD or ThirdEye system.

Use the maintained [Export Device Inventory](../../Advanced/Export-Device-Inventory/) example instead. It provides tested Python, Node.js, and PowerShell implementations with API-key authentication, multiple managed networks, complete pagination, filtering, atomic writes, and CSV or JSON output.

Related Python 2 material remains in the consolidated [Python 2](../Python-2/) historical collection.
