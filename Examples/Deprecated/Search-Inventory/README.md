# Deprecated Inventory Search Examples

These Perl and Ruby scripts are the original interactive inventory-search demonstrations. They use hard-coded connection details or username-and-password authentication, disabled TLS verification, a fixed managed network, and older calling conventions.

They are retained only for historical inspection and should not be used on a current netLD or ThirdEye system.

Use the maintained [Search Inventory](../../Getting-Started/Search-Inventory/) example instead. It provides current Python, Node.js, and PowerShell implementations with API-key authentication and documented named JSON-RPC parameters.
