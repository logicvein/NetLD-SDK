# Deprecated Configuration Export Examples

These Perl and Ruby scripts are the original incremental configuration-export examples. They use the undocumented `Configuration.retrieveConfigsSince` method, username-and-password authentication, disabled TLS verification, and the private `inventoryServlet` endpoint.

They are retained only for historical inspection and should not be used on a current netLD or ThirdEye system.

Use the maintained [Archive Configuration Revisions](../../Advanced/Archive-Configuration-Revisions/) example instead. It provides Python, Node.js, and PowerShell implementations using documented APIs, API-key authentication, pagination, atomic state handling, full or latest-revision baselines, tests, and failure reporting.

Related Python 2 material remains in the consolidated [Python 2](../Python-2/) historical collection.
